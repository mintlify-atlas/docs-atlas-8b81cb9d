sfsu (Stupid Fast Scoop Utils) is a Rust-powered CLI that supercharges your Scoop workflow. It provides drop-in replacements for the slowest Scoop commands — search, list, status, and more — running them 30–100× faster through parallel execution. sfsu works alongside your existing Scoop installation and can be wired in transparently via shell hooks so you never notice the switch.

## Why sfsu?

Scoop is a great package manager, but its PowerShell implementation can be slow — especially for search and list operations over large bucket collections. sfsu reimplements the hottest code paths in Rust using Rayon for parallelism, cutting wait times dramatically.

## Quick Install

```powershell
scoop bucket add extras
scoop install sfsu
```

Once installed, wire sfsu into your shell so `scoop` commands are intercepted automatically:

```powershell
# Add to your PowerShell profile
Invoke-Expression (&sfsu hook)
```

<Steps>
  <Step title="Install sfsu">
    Add the `extras` bucket and install sfsu via Scoop — see the [Installation guide](/installation) for all options.
  </Step>
  <Step title="Set up shell hooks">
    Add the hook line to your shell profile so sfsu handles compatible `scoop` commands transparently — see [Shell Hooks](/usage/hook).
